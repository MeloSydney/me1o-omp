# linux-ut arm64 degraded auto-stub restore (10028)

## When to use
After stub regeneration in kernel-arch-arm64 (or similar workspaces), full-prototype auto stubs degrade to `int f(void)` because the real prototype lives in a kernel header absent from the fake tree (FAKE-MISSING-REAL-EXTERN, e.g. `parse_crashkernel{,_high,_low}` in `include/linux/crash_core.h`). Symptoms: callback-side SIGSEGV (garbage output pointers), lost decision coverage, or stub syntax conflicts.

## Procedure
1. Compare regenerated `ws/kbuild/stubs/autogenerated/auto_*.c` with the delivered `ws.full.verify-backup-*/kbuild/stubs/autogenerated/auto_*.c` for the symbol's arity.
2. Write a workspace-local idempotent, fail-closed patch script (model: `parasoft/kernel-arch-arm64/patch_arm64_crashkernel_stubs_1112.py`):
   - Skip when the full-prototype signature already present.
   - Replace the reduced `int name(void)` block (also handle a broken opener missing `/**` from an older patch) with the full block sourced from the delivered ws.full.
   - Abort the run when a stub is present but neither form matches, or count != 1 after patch.
3. Hook it into `run_ut.sh` right before `exec "$CPPTESTCLI"`, alongside the other `*_1111.py` workspace patch scripts; back up run_ut.sh first (`run_ut.sh.bak-*`).
4. Shared-header conflicts (e.g. `fake_kernel_headers/linux/kasan-enabled.h` `int kasan_hw_tags_enabled(void);` vs `kasan.h` bool usage): fix via workspace `local_fake_headers/linux/<header>` overlay — never edit the shared tree from the ws role. Drop macros like `__init` from overlay prototypes (undefined in stub TUs).
5. Rerun `LANG=C.UTF-8 LC_ALL=C.UTF-8 ./run_all.sh`; verify 617/617 PASS and gate coverage.

## Conventions
- TestSuite-side fixes for degraded/void stubs: set `linux_ut_stage27_current_regs` before copy_thread tests, set `current = &task` for show_regs, register `memblock_alloc_try_nid` callback returning a static buffer, void-stub callbacks take only `CppTest_StubCallInfo*`.
- Escalate shared-header drift (kasan-enabled.h mtime change) to tools-improve via agent-message with sender name; do not patch the shared tree.
